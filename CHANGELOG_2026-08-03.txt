Bettle GIF Maker — Work Summary (2026-08-03)
==============================================

Starting point: a single-GIF workflow — one flat list of frames, one shared
settings panel, one output preview/download.

WHAT CHANGED TODAY

1. Multi-job queue
   - Each drop/file-pick now creates an independent "job" instead of
     replacing or appending to a single frame list.
   - Every job keeps its own settings (delay, dither, loop, size, file name)
     rather than sharing one global settings panel.
   - Jobs can be processed individually ("Make Selected GIF") or all at once
     ("Make GIF" / "Make N GIFs"), one at a time.

2. Left panel redesign (iterated through a couple of mockups)
   - A compact "Jobs Queued" list at the top: thumbnail, editable file name,
     status, download, and remove per job.
   - Below it, every job's full frame grid is shown at once (not just the
     active job's), each with a colour swatch to pick which job's settings
     are being edited.
   - Drag-and-drop reordering added at two levels: frames within a job, and
     whole jobs within the queue.

3. File naming and saving
   - Default file names are now derived from the imported file's own name
     instead of a generic placeholder, with automatic (2), (3)... suffixes
     on collisions.
   - Settings panel gained a "File names" button list (one per queued job);
     clicking one opens the OS "Save As" dialog (File System Access API) to
     choose where that job's GIF should be written, with a prompt() fallback
     on browsers that don't support it.
   - Downloading a job now writes straight to its chosen save location if
     one was set, otherwise falls back to a normal browser download.

4. Preview panel
   - Switched from a single preview to a grid of tiles, one per job, sized
     to fill the available space.
   - Added a "Download All" button that downloads every completed job.
   - A prev/next "Job X of N" header was added and then removed per
     feedback.
   - Completed tiles show the GIF's file size instead of repeating the
     status text already shown elsewhere.

5. Layout and polish
   - Fixed the page so it fits the browser window without needing to
     scroll the whole page — each panel now scrolls internally instead.
   - Removed the up/down spinner arrows from the width/height number
     inputs.
   - Added a "Make Selected GIF" button, aligned directly above "Make GIF".
   - Status bar now reports how long a run took (e.g. "Queue complete —
     4.2s") in addition to live progress messages.

6. Repo/housekeeping
   - Committed and pushed all of the above to origin/main on GitHub.
   - Added robots.txt to keep the site out of search engine indexing for
     now.
   - Wrote FEATURES.txt documenting the full current feature set.
