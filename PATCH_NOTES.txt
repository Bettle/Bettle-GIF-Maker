Bettle GIF Maker — Patch Notes
Unreleased (not yet pushed)

DITHER ALGORITHM
- Added "Pattern" — ordered dithering using a 4x4 Bayer matrix. Deterministic:
  exporting the same job twice produces identical output.
- Added "Noise" — random per-pixel dithering. Produces a different result
  each export by design (no repeating pattern).
- Removed "Atkinson" (was a leftover option, not part of the Photoshop-style
  set this app is now matching).
- Selecting "None" now automatically zeroes the Dither (strength) field, so
  the UI doesn't show a strength value while no dithering is actually being
  applied. Switching to Diffusion, Pattern, or Noise afterward automatically
  sets it back to 100.
- "Diffusion" (Floyd-Steinberg) is unchanged.

COLOUR REDUCTION
- This dropdown previously did nothing — the setting was stored but never
  read at export time. It's now fully wired up.
- Added "Perceptual" — builds the palette weighted toward colours the human
  eye is more sensitive to (luma-weighted), and matches dithered pixels to
  that palette using the same weighting.
- Added "Adaptive" — builds the palette weighted toward the most populous
  colour regions in the actual image, rather than raw colour range alone.
- Added "Restrictive (Web)" — uses the fixed 216-colour web-safe palette
  instead of building one from the image.
- "Selective" (the existing default) is unchanged — same output as before.

NOTES
- All four dither modes and four colour-reduction modes were verified to
  produce genuinely different output in a headless browser, with no
  console errors across every combination.
- Restrictive correctly reports "still over KB limit" rather than wasting
  compression attempts trying to shrink a palette that can't shrink.
